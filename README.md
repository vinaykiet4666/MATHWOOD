 Web Application Details

### Project Title
**Movie Recommender Mini-System using SVD**

### Technologies Used
- HTML5
- CSS3
- JavaScript
- Singular Value Decomposition (SVD)
- Low-Rank Matrix Approximation
- Collaborative Filtering

### Project Description
This web application demonstrates how a movie recommendation system can be built using **Singular Value Decomposition (SVD)**. It analyzes a user-movie rating matrix, reduces it to its most important taste dimensions, predicts missing movie ratings, and recommends movies that a user has not yet rated.

### Key Features
- Telugu movie-based recommendation system
- User-movie rating matrix
- SVD-based recommendation algorithm
- Low-rank approximation using top 2 singular values
- Prediction of missing ratings
- Personalized movie recommendation
- Interactive and responsive web interface
- Premium cinematic UI design

### Mathematical Concept
The rating matrix is decomposed as:

**R = UΣVᵀ**

The system keeps the top 2 singular values to create a low-rank approximation:

**R₂ = U₂Σ₂V₂ᵀ**

The predicted ratings are then used to recommend the highest-rated movie that the user has not already rated.

### How to Run
1. Download the HTML file.
2. Open the HTML file in a web browser.
3. Select a user.
4. View the predicted ratings.
5. Get the recommended movie.
